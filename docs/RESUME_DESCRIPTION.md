# Краткое описание для резюме после самостоятельного запуска

**Credit Risk PD Scoring — модель оценки вероятности дефолта (учебный проект)**

Разработала воспроизводимый учебный ML-пайплайн для оценки вероятности дефолта на синтетических кредитных заявках: подготовка и анализ данных на Python/pandas, SQL-витрина признаков в SQLite, сравнение Logistic Regression и XGBoost. Реализовала временное разделение train/validation/test, оценку ROC-AUC, Gini, PR-AUC и Brier Score, проверку калибровки вероятностей, анализ стабильности признаков (PSI) и автоматические тесты. Подготовила графики и документацию модели.

**Навыки:** Python, pandas, NumPy, SciPy, scikit-learn, XGBoost, SQL, SQLite, Feature Engineering, Credit Scoring, Model Validation, pytest, GitHub Actions.

Не заявлять: реальный банковский опыт, production Feature Store, разработку моделей PD для ИП/юрлиц, если опыт не получен отдельно.
