# Вопросы для технического собеседования

**Что такое PD?** Probability of Default — вероятность дефолта на определенном горизонте при заданном определении дефолта.

**Зачем временной split?** Для демонстрации оценки на более поздних заявках и снижения риска утечки будущего в прошлое. В реальных данных важны окно наблюдения метки и point-in-time доступность признаков.

**Почему Logistic Regression?** Хороший, сравнительно интерпретируемый baseline с логит-ссылкой; бустинг может находить нелинейности и взаимодействия, но не обязан побеждать.

**Что показывают ROC-AUC/Gini?** Способность ранжировать относительно риска, Gini = 2*AUC−1. Это не показатель калибровки вероятностей.

**Что такое Brier Score?** Средний квадрат ошибки вероятности. Меньше лучше, нужен для качества PD.

**Почему калибровка может ухудшить результат?** Изотонический маппинг может переобучиться на validation, а распределение test может отличаться.

**Почему accuracy недостаточно?** При низкой частоте дефолтов предсказание «не дефолт» всем даст высокую accuracy, но не будет полезным.

**Что такое PSI?** Population Stability Index — описательное сравнение распределений признаков/скоров между выборками. Пороги и интерпретация зависят от контекста, не универсальны.

**Чем SQL-витрина отличается от Feature Store?** Витрина — таблица подготовленных признаков. Полноценный Feature Store организует версионирование, point-in-time retrieval, согласованность offline/online признаков и обслуживание моделей. Здесь только иллюстрация в SQLite.

**Что с банковской применимостью?** Данные целиком синтетические; оценка на реальных клиентах и регуляторная валидация не проводились.
