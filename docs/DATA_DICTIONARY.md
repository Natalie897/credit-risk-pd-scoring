# Data Dictionary

| Поле | Значение | На момент заявки? |
|---|---|---|
| `application_id` | Уникальный вымышленный ID заявки | Да, исключён из модели |
| `application_date` | Дата заявки (используется для временного split) | Да, исключена из модели |
| `age` | Возраст заявителя (21–65) | Да |
| `annual_income` | Условный годовой доход | Да, возможны NULL |
| `employment_years` | Условный стаж | Да, возможны NULL |
| `debt_to_income` | Доля долговых платежей в доходе, 0–1 | Да |
| `credit_utilization` | Коэффициент использования лимита, 0–1 | Да, возможны NULL |
| `delinquencies_12m` | Число прошлых просрочек за 12 месяцев до заявки | Да |
| `loan_amount` | Запрошенная сумма | Да |
| `loan_term_months` | Срок в месяцах | Да |
| `region` | Условная географическая категория | Да |
| `channel` | Канал оформления | Да |
| `customer_segment` | `individual`/`small_business` (условно) | Да |
| `loan_to_income` | `loan_amount / annual_income` (SQL-признак) | Да |
| `has_delinquency` | Признак наличия прошлых просрочек (SQL-признак) | Да |
| `default_12m` | **Целевая метка**, исход дефолта за 12 месяцев после заявки | **Нет**, исключена из признаков |

Таблицы SQLite: `raw_applications`, `feature_store_applications`. Вторая содержит метку для обучения модели, но в инференсе её надо отделять от point-in-time набора признаков.
